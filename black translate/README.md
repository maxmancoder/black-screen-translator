# مترجم صفحه و تصاویر (افزونه کروم) — نسخه ۲.۱

ترجمه‌ی زنده‌ی کل صفحه: متن‌ها، دکمه‌ها، placeholder فیلدها، متن داخل SVG و **متن داخل عکس‌ها** (OCR).
ترجمه دقیقاً روی متن اصلی نشان داده می‌شود و با اسکرول و محتوای تازه، خودکار ادامه پیدا می‌کند.

---

## تغییرات نسخه ۲.۱.۱ — رفع «فقط یک عکس ترجمه می‌شود»

چهار نقص که باعث می‌شد ترجمه‌ی عکس‌ها بعد از یکی دو تصویر **برای همیشه** بایستد (در حالی که ترجمه‌ی متن عادی کار می‌کرد):

| نقص | نشانه | اصلاح |
|---|---|---|
| `stop()` با `TypeError: Assignment to constant variable` نصفه اجرا می‌شد (`imgRectCache` با `const` تعریف شده بود و در `stop()` مقداردهی می‌شد) | با هر تغییر تنظیمات از پنل، `stop(); start();` در خطا می‌شکست و ترجمه دیگر روشن نمی‌شد؛ صف عکس‌ها و شمارنده‌های هم‌زمانی پاک نمی‌شدند | `imgRectCache` به `let` تغییر کرد |
| اسلات هم‌زمانی OCR در `runImageJob` فقط در مسیر موفق آزاد می‌شد | اگر نشست عوض می‌شد یا خطای غیرمنتظره رخ می‌داد، `imageActive` بالا می‌ماند و با پرشدن ظرفیت، **هیچ عکس دیگری** پردازش نمی‌شد | آزادسازی اسلات در `finally` |
| درخواست OCR مهلت نداشت؛ یک Worker گیرکرده یا offscreen بی‌پاسخ، اسلات را برای همیشه اشغال می‌کرد | عکس اول ترجمه می‌شد و بقیه در صف می‌ماندند | `sendTimed()` + تنظیم «مهلت خواندن هر عکس» (پیش‌فرض ۴۵ ثانیه)؛ قفل اسکرین‌شات (`captureBusy`) هم در `finally` آزاد می‌شود |
| در `offscreen.js`، Workerهای بسته‌شده از `pool.workers` حذف نمی‌شدند و اگر ساخت Worker شکست می‌کرد، منتظرهای صف هرگز بیدار نمی‌شدند | پول OCR «پر» به نظر می‌رسید و درخواست‌های OCR **بی‌پاسخ** می‌ماندند | حذف Worker مرده از پول، بیدارکردن منتظرها با خطا، و مهلت روی `recognize` (Worker گیرکرده دور انداخته می‌شود) |

همچنین عکس‌هایی که خوانده نمی‌شوند حالا شمرده می‌شوند: در نوار وضعیت صفحه `تصاویر: ۳/۶ (۲ خطا)` و در پنل `۲ عکس خوانده نشد` نمایش داده می‌شود (جزئیات با روشن‌کردن «لاگ عیب‌یابی» در کنسول).

### تست‌های تازه
```bash
node tools/imgsmoke.js    # مسیر واقعی تصاویر در content.js: صف OCR، اسکرول، ری‌استارت، OCR گیرکرده
node tools/ocrsmoke.js    # پول Worker در offscreen.js: هم‌زمانی، خطای ساخت، Worker گیرکرده
```
هر دو روی کد قبلی این نقص‌ها را شکست می‌دهند (صف عکس‌ها روی `۱/۶` قفل می‌شد).

## تغییرات نسخه ۲.۱

### ۱) سرعت ترجمه واقعاً بهتر شد
| کار | قبل | بعد |
|---|---|---|
| خواندن موقعیت متن‌ها | در هر فریم اسکرول، موقعیت تا ۳۰۰۰ متن دوباره از DOM خوانده می‌شد | موقعیت‌ها کش می‌شوند؛ در هر فریم اسکرول **هیچ** خواندن DOM لازم نیست (کادرهای absolute خودشان با سند حرکت می‌کنند) |
| ساخت کادر ترجمه | برای همه‌ی متن‌های صفحه کادر ساخته می‌شد (هزاران div) | کادر فقط برای متن‌های نزدیک دید ساخته می‌شود و کادرهای دور «خوابانده» و حذف می‌شوند (DOM سبک) |
| اندازه‌گیری فونت | برای همه‌ی آیتم‌ها، هر بار | فقط برای کادرهای دیده‌شده و با کش؛ بقیه با IntersectionObserver |
| صف ترجمه | مرتب‌سازی کامل در هر فراخوانی | مرتب‌سازی throttle‌شده + اولویت «بخش دیدنی» |
| هم‌زمانی | ۴ درخواست ثابت | قابل تنظیم تا ۱۲ (پیش‌فرض ۶) + صف اولویت‌دار در background |
| متن‌های بی‌فایده | همه فرستاده می‌شدند | متن هم‌زبان با مقصد، متن‌های خیلی کوتاه و کد ناخواسته رد می‌شوند |
| کش | فقط در حافظه‌ی service worker (با خوابیدن پاک می‌شد) | کش حافظه + دیسک (۳۲ سطل LRU) — بازدید بعدی همان سایت فوری است |
| OCR | ۳ پاس همیشه، تصاویر تا ۳۰۰۰px | پاس‌های تطبیقی (psm 11 و معکوس فقط وقتی لازم است)، رد کردن سریع تصاویر بی‌متن، سقف اندازه قابل تنظیم (پیش‌فرض ۱۸۰۰px)، رمزگشایی با createImageBitmap |

نتیجه: در حالت «هوشمند» معمولاً **زیر نیم‌ثانیه** متن‌های جلوی چشم ترجمه می‌شوند و صفحات سنگین هم صفحه را قفل نمی‌کنند.

### ۲) بخش اتصال به APIها بازنویسی و درست شد
- **آدرس‌دهی هوشمند**: اگر Base URL را با یا بدون `/v1`، با `/chat/completions` یا بدون آن وارد کنید، آدرس نهایی درست ساخته می‌شود.
- **Azure OpenAI** خودکار با هدر `api-key` و `api-version` مدیریت می‌شود.
- **مدل‌های استدلالی** (`o1/o3/gpt-5/deepseek-reasoner/…`) خودکار `max_completion_tokens` می‌گیرند و `temperature` برایشان فرستاده نمی‌شود.
- اگر سرویس `temperature` یا `response_format` را قبول نکند، درخواست **خودکار بدون آن‌ها** دوباره فرستاده می‌شود.
- **قالب نشانه‌دار** (`[[[1]]]…`) به‌جای JSON خالص: هم توکن کمتری مصرف می‌شود، هم چندخطی‌ها و رشته‌های سخت درست ترجمه می‌شوند؛ اگر پارس شکست بخورد، دسته به‌صورت بازگشتی نصف می‌شود.
- **دکمه‌ی «دریافت لیست مدل‌ها»**: با یک کلیک مدل‌های موجود سرویس شما خوانده و به‌صورت لیست پیشنهادی نمایش داده می‌شود (انتهای نام مدل‌های اشتباه تمام می‌شود).
- **تست اتصال گام‌به‌گام**: ساخت آدرس → دریافت لیست مدل‌ها → ترجمه‌ی نمونه با همان مسیر افزونه؛ هر گام زمان و پیام خطای دقیق دارد.
- **تلاش دوباره و محدودیت نرخ**: خطاهای ۴۲۹/۵xx با backoff و احترام به `Retry-After` دوباره تلاش می‌شوند؛ تأخیر بین درخواست‌ها قابل تنظیم است.
- **درخواست تکراری اشتراکی**: اگر چند فریم یا چند بخش صفحه یک متن را بخواهند، فقط یک درخواست ساخته می‌شود.
- **خطای یک دسته = فقط همان دسته**: بقیه‌ی صفحه ترجمه می‌شود و متن ترجمه‌نشده، متن اصلی خودش را نشان می‌دهد (به‌جای خراب‌شدن کل ترجمه). آیتم ناموفق در کش ذخیره نمی‌شود.
- **موتورهای تازه**: Microsoft Translator، LibreTranslate (سرور خودتان) و ۲۰+ پیش‌تنظیم هوش مصنوعی.
- **Google رایگان**: اگر سرویس سریع مسدود/فیلتر باشد، با یک circuit breaker سریع به روش `gtx` سوییچ می‌کند (و روش gtx هم حالا **چند متن در یک درخواست** می‌فرستد، نه یک درخواست برای هر متن).

### ۳) تنظیمات مهم و بیشتر در پنل (تب‌بندی‌شده)
پنل به ۶ تب تقسیم شد: **ترجمه | سرعت | موتور/AI | تصاویر | ظاهر | پیشرفته**

- **ترجمه**: سه حالت «صفحه‌ی فعلی»، «هوشمند» (جدید — پیش‌فرض) و «کل صفحه»؛ زبان مبدأ/مقصد؛ شورتکات؛ ترجمه‌ی خودکار سایت‌ها؛ محتوای پویا.
- **سرعت**: پروفایل‌های آماده (سریع‌ترین/متعادل/دقیق‌ترین)، درخواست هم‌زمان، اندازه‌ی دسته (متن/کاراکتر)، مهلت، تلاش دوباره، تأخیر، حالت سبک DOM، فاصله‌ی خواباندن کادر، حاشیه‌ی ساخت کادر، فاصله‌ی بررسی، زمان تکه‌ی اسکن، حداقل طول متن، رد کردن متن هم‌زبان مقصد، نمایش نوار وضعیت + **سرعت (متن/ثانیه)**.
- **موتور/AI**: انتخاب موتور، کلیدها، لحن DeepL، منطقه‌ی Microsoft، آدرس LibreTranslate، انتخاب سرویس AI، Base URL، مدل (+لیست مدل‌ها)، کلید، temperature، حداکثر توکن، قالب خروجی، اندازه‌ی دسته‌ی AI، system prompt دلخواه، **واژه‌نامه**، هدرهای اضافی HTTP، fallback به موتور رایگان، و مدیریت کش (فعال/دیسکی/حداکثر/پاک‌کردن/آمار).
- **تصاویر**: فعال/غیرفعال، تصاویر پس‌زمینه، رد کردن تصاویر بی‌متن، متن روشن روی زمینه تیره، فقط داخل دید، زبان OCR، کیفیت، تعداد هم‌زمان، حداقل اطمینان، بزرگ‌ترین ضلع تصویر، ظرفیت کش OCR.
- **ظاهر**: رنگ کادر (ثابت/هم‌رنگ سایت)، رنگ متن (خودکار/ثابت)، شفافیت کادر، اندازه‌ی فونت، فاصله‌ی داخلی، گردی گوشه، فونت دلخواه، جهت متن.
- **پیشرفته**: دکمه‌های فرم و placeholder، کد داخل جمله، بلوک‌های کد، احترام به `translate="no"`، **سلکتورهای CSS نادیده‌گرفتنی**، لاگ عیب‌یابی، **صفحه‌ی وضعیت** (درخواست‌ها، میانگین پاسخ، کش، اسلات‌ها، وضعیت سرویس Google، تعداد متن هر تب و سرعت لحظه‌ای)، **خروجی/بازیابی تنظیمات** و بازگرداندن پیش‌فرض‌ها.

## نصب / به‌روزرسانی
1. `chrome://extensions` ← **Developer mode** را روشن کنید.
2. اگر نسخه‌ی قبلی نصب است، روی 🔄 (Reload) بزنید؛ وگرنه **Load unpacked** و انتخاب پوشه‌ی `page-translator`.
3. تب‌های باز را یک بار رفرش کنید.
4. شورتکات پیش‌فرض **Alt + Shift + T** است (هم داخل صفحه، هم سراسری کروم از `chrome://extensions/shortcuts`).

> برای OCR زبان‌های غیر از انگلیسی، مدل زبان از اینترنت دانلود و کش می‌شود؛ برای متن فارسی/عربی مدل `fas`/`ara` لازم است.
> مدل انگلیسی داخل خود افزونه است و آفلاین کار می‌کند.

## عیب‌یابی سریع
- **ترجمه نمی‌شود / کند است** → تب «موتور/AI» → **تست اتصال**؛ گام‌های قرمز، دقیقاً همان چیزی است که باید درست شود (کلید، آدرس، مدل، فیلترینگ).
- **خطای ۴۲۹ یا کندی سرویس AI** → «تعداد درخواست هم‌زمان» و «متن در هر درخواست» را کم کنید یا «تأخیر بین درخواست‌ها» را بالا ببرید.
- **متنی از عکس‌ها جا می‌افتد** → «حداقل اطمینان OCR» را کم کنید، زبان OCR را درست انتخاب کنید یا «بزرگ‌ترین ضلع تصویر» را زیاد کنید.
- **بعضی عکس‌ها ترجمه نمی‌شوند** → در نوار وضعیت، شمار «خطا» را ببینید؛ اگر دانلود تصویر بسته باشد افزونه از اسکرین‌شات استفاده می‌کند (عکس باید تقریباً کامل داخل دید باشد). زبان OCR هم با زبان متن داخل عکس باید یکی باشد.
- **صفحه سنگین است** → «حالت سبک» را روشن بگذارید و پروفایل «سریع‌ترین» را بزنید.
- **متن فارسی روی سایت انگلیسی نمی‌آید؟** → «متن هم‌زبان با مقصد رد شود» را خاموش کنید یا زبان مبدأ را دستی انتخاب کنید.

## تست‌های خودکار (بدون نیاز به مرورگر)
```bash
cd page-translator
node tools/selftest.js    # ۱۵۰+ تست منطق: تشخیص زبان، آدرس‌سازی API، پارس خروجی مدل، سیم‌کشی تنظیمات
node tools/domsmoke.js    # اجرای واقعی content.js روی DOM شبیه‌سازی‌شده: اسکن → ترجمه → رسم کادر
node tools/imgsmoke.js    # مسیر واقعی عکس‌ها: صف OCR، اسکرول، ری‌استارت، OCR گیرکرده
node tools/ocrsmoke.js    # پول Worker در offscreen.js: هم‌زمانی، خطای ساخت، Worker گیرکرده
```

## پرونده‌ها
```
manifest.json     تنظیمات افزونه (MV3)
defaults.js       تنظیمات پیش‌فرض، پیش‌تنظیم سرویس‌ها و توابع کمکی مشترک
background.js     موتورهای ترجمه، صف/کش/ذخیره‌سازی، OCR و تست اتصال
content.js        اسکن صفحه، صف اولویت‌دار، رسم و به‌روزرسانی کادرها
offscreen.js      Tesseract.js و پردازش تصاویر
popup.html/css/js پنل تنظیمات تب‌بندی‌شده
lib/              Tesseract و مدل انگلیسی (آفلاین)
tools/            تست‌های خودکار
```

## کارهای پیشنهادی بعدی
- ترجمه‌ی متن انتخاب‌شده با منوی راست‌کلیک.
- لیست سیاه/سفید دامنه‌ها برای ترجمه‌ی خودکار.
- ترتیب دلخواه موتورها (زنجیره‌ی fallback).
- حالت هم‌زمان «متن اصلی + ترجمه» (دو زبانه).
